# Discord Dark (SillyTavern)

Thème mobile OLED façon Discord : fond noir, avatars ronds à gauche, nom en gras + heure, messages sans bulles, barre de saisie en pilule, accents blurple. Léger (pas de flou, pas d’animations ajoutées).

Auteur : Hydra wave · pour SillyTavern 1.19+

## Installation (iPhone)

1. Ouvre [Discord_Dark.json](https://raw.githubusercontent.com/hydravnss/discord-dark-theme/main/Discord_Dark.json) et enregistre le fichier (Partager → Enregistrer dans Fichiers).
2. SillyTavern → **Paramètres utilisateur** → **Thème**.
3. **Importer** le JSON (ou colle le contenu de `Discord_Dark.css` dans Custom CSS si tu préfères garder ton thème actuel et n’appliquer que le style).

## Contenu

| Fichier | Rôle |
|---------|------|
| `Discord_Dark.json` | Thème complet (couleurs + Custom CSS) |
| `Discord_Dark.css` | CSS seul, si tu veux le coller à la main |

Astuce : avec beaucoup d’extensions, garde **reduced motion** / peu d’animations pour ne pas alourdir la frappe.
